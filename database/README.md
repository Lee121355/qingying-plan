# 食谱数据层

网站当前部署在 GitHub Pages，无法直接运行服务端 SQL。因此生产页面会在浏览器中创建 `qingying-recipes` IndexedDB，并用 `app.js` 中的 12 道日常食谱初始化。数据库只存公共食谱，用户计划和记录仍按账号隔离保存在本机。

`schema.sql` 与 `seed.sql` 是后续接入 PostgreSQL 服务时使用的结构和初始数据，包含食谱营养数据、结构化食材及份量、制作步骤，以及 B站、抖音和小红书的同名教程搜索入口。

外部平台链接是搜索入口，不代表本站复制、抓取或验证了平台内容。本站营养记录以本地食谱的食材份量和步骤为准。
